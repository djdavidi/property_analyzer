# Fix plan for the 2026-11-16 adversarial findings

Status: **accepted**, 2026-11-16. The user accepted every recommended default in
[section 2](#2-decisions-needed) ("use the defaults"). Implementation has not started.
Decision IDs D1–D12 are separate from the review's imagery findings, which the phase
tables write as "review D1"–"review D6".
The plan covers every finding in [ADVERSARIAL-REVIEW-2026-11-16.md](ADVERSARIAL-REVIEW-2026-11-16.md)
(IDs A1–G7 and H1–H19, plus the cross-checked items from the separate review, listed as R1–R20)
on `origin/main` `a11f4db`. No code has changed yet.

## 1. Approach

Fix in an order where each phase makes the next one checkable:

1. **Make the suite trustworthy** (Phase 0).
2. **Make saved results survivable** (Phase 1), so later fixes don't quarantine
   everything.
3. **Fix the money** (Phase 2).
4. **Fix the geometry and routing** (Phase 3).
5. **Fix the pilot and capacity layer**, which depends on 2 and 3 (Phase 4).
6. **Fix acquisition and prospects** (Phase 5).
7. **Measure accuracy** (Phase 6), only after the above.
8. **Clean up docs** (Phase 7) and, with permission, **rerun properties** (Phase 8).

Rules applied in every phase:

- **Verification.** Each fix lands with a regression test. Most of the scripts in
  `review-2026-11-16-repros/` convert directly into tests. Money tests use expected
  values worked out by hand from the tariff, not copied from code output. A phase is
  "verified" only when the full documented suite is green
  (`.venv/bin/python -m unittest discover -s tests`), not a hand-picked subset.
- **Constraints from AGENTS.md and PRD.** Keep the GIS/jurisdiction boundary and
  immutable inputs. Missing evidence never becomes zero. No property reruns or
  network use without permission.
- **Size.** Rough sizes are S (under half a day), M (about 1 day) and L (2–3 days)
  of focused agent work.
